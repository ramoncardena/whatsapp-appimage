# 🖼️ v2.2.1 - App Catalog Metadata

## ✨ Added

- **AppStream metadata**: the AppImage now describes itself (summary, description, links, screenshots and release history), so software catalogs like [appimage.github.io](https://appimage.github.io) and AppImage managers can show proper information about WhatsDesk.

No changes to the app itself: your session, settings and privacy features stay exactly as they were.

---

## 🚀 Upgrading

Update with [AppImageUpdate](https://github.com/AppImageCommunity/AppImageUpdate) or [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) if you're on v2.2.0, or download by hand:

1. Quit WhatsDesk (right-click the tray icon → **Quit**)
2. Download `WhatsDesk-2.2.1.AppImage` below
3. Make it executable and run it:
   ```bash
   chmod +x WhatsDesk-2.2.1.AppImage
   ./WhatsDesk-2.2.1.AppImage
   ```

Upgrading from v2.0.0 or earlier? Your session moves automatically from `~/.config/WhatsApp` to `~/.config/WhatsDesk`, see the [v2.1.0 release notes](https://github.com/ramoncardena/whatsdesk/releases/tag/v2.1.0).
